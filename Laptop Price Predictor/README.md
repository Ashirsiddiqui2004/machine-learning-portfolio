# Laptop Price Predictor

## 📌 Project Overview
This project predicts laptop prices based on specifications such as brand, RAM, storage, processor, and other features using machine learning regression models.

## 📊 Dataset
- Laptop specifications dataset
- Features include brand, RAM, SSD/HDD size, CPU, and screen size

## ⚙️ Methodology
- Data cleaning and preprocessing
- Feature encoding
- Model training using regression algorithms
- Performance evaluation

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📈 Result
The model predicts laptop prices with reasonable accuracy based on hardware specifications.
